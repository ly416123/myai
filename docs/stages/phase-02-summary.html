上一阶段的问题

阶段一完成了单次模型与工具交互循环，但运行上下文仅保存在内存中。项目缺少任务 ID、生命周期状态、持久化检查点和恢复入口，也没有对任务总工具调用量、失败类别及执行耗时做统一记录。

  • 进程中断后无法知道任务停在哪一步，也无法安全恢复。
  • 工具执行可能产生外部副作用，直接重放存在重复操作风险。
  • 模型调用轮数之外，缺少总工具调用数和任务时限等预算边界。
  • 仅凭最终回答难以判断模型调用、工具执行和故障恢复的过程。
  • 没有可重复的固定样例验证边界行为和恢复语义。

本阶段解决的问题与设计

问题实现方式选型与设计理由
任务状态不明确、无法恢复 增加 RunRecord、RunStatus、状态变更记录和 RunStore 抽象；实现内存 Store 与本地 JSON 文件 Store。 保留存储边界，使 Runtime 不依赖具体介质。阶段二按当时范围采用 JSON 文件和原子替换作为单机实现；它不提供跨进程锁、事务协调、集群高可用或生产数据治理能力。
工具调用崩溃后可能被重复执行 工具调用先持久化为 PENDING，执行前转为 IN_PROGRESS，执行后记录结果。恢复时继续安全的 PENDING 步骤；旧 IN_PROGRESS 步骤标记为 INDETERMINATE，不自动重放。 本地检查点无法与任意外部系统事务化。将结果未知与失败区分，优先避免静默重复副作用；不宣称 exactly-once。
执行量和时长不受完整约束 加入模型调用上限、工具调用总上限、重试上限和任务 Deadline；模型 SDK 内部重试关闭，由 Runtime 统一计数。 把预算放在运行时配置中，使一次任务有明确资源边界，也便于在测试中使用短时限和小额度验证行为。
错误难以分类且可能泄露异常正文 定义模型和工具失败类别；日志及运行摘要记录分类，不保留原始供应商错误正文。 分类足以支持重试决策和故障定位，同时减少凭据、参数等敏感内容进入日志。
缺少执行过程的可观察性 为运行和步骤记录 ID、状态、时间、耗时、调用次数、恢复标记及可获取的 Token 用量；CLI 增加 /runs 和 /resume <runId>。 先用本地运行记录和结构化日志验证功能路径；当时范围未建设企业级指标、告警、仪表盘和分布式追踪。
缺少稳定回归依据 使用 Fake ModelClient、Fake/In-memory Store 和确定性工具覆盖普通回答、预算、失败、Deadline、取消、超时未知状态和恢复场景。 避免测试依赖真实模型、网络和密钥，让状态与恢复行为可重复验证。固定样例只验证已知行为，不代表模型质量。

取消问题的修复与复验

初次验收发现两项取消风险：取消模型等待时没有中断活动模型任务；取消请求可能与成功终态提交竞争。

  • 增加运行期 RunControl，保存取消标记与活动模型 Future；取消时中断模型任务，任务启动和取消并发时也会检查取消标记。
  • 取消请求与运行终态提交使用同一协调锁，由执行线程确认并持久化终态，避免取消状态被旧运行记录覆盖。
  • 新增测试验证模型线程收到中断，以及模型返回与取消竞争时最终状态仍为 CANCELLED、不会提交最终回答。

修复后重新执行干净构建，20 项测试全部通过。

实际效果

  • CLI 可以查看本地运行摘要，并对磁盘中仍处于非终态的任务发起恢复。
  • 每次执行可以通过 runId 回看运行状态变化、模型/工具步骤、耗时和失败类别。
  • 进程恢复会继续尚未开始的工具调用；执行中断的工具不会被静默重放。
  • 模型重试受总模型调用预算和任务 Deadline 限制；工具数量受独立上限约束。
  • 新增恢复、持久化、预算、失败处理、超时、取消和评测样例；干净测试结果为 20/20 通过。

这些是代码路径与自动化样例验证的结果，不代表已测量生产吞吐、真实模型成功率或线上成本。

已知限制与下一步

  • 本地 JSON Store 仅适用于阶段二定义的单机、单实例范围；尚无多进程并发恢复同一 Run 的租约或锁，不满足多实例生产部署需求。
  • 工具取消或超时不保证底层外部副作用撤销；真实副作用工具仍需工具端幂等、人工审批或事务协议。
  • 模型请求在进程中断后可能重新发送，因此可能产生重复模型费用。
  • 检查点包含消息历史、工具参数和工具结果；运行目录需要按敏感数据保护。
  • 固定回归评测不验证真实模型是否正确选择工具，也不等同于完整质量、安全或生产可用性评估。

阶段二之后的工程缺口：RunStore 仍是内存/本地 JSON 单实例实现；没有数据库事务、跨进程协调、容灾恢复、数据保留策略和企业级监控；评测仍是 Fake ModelClient 固定样例，没有真实模型评测集。这些是当时阶段范围留下的客观限制，不意味着项目目标为学习用途。
